# Briefing IA - Templo Consulting

Repositorio del agente que genera el briefing diario de novedades en inteligencia artificial.

## Estructura

- `briefings/` - una edicion por dia, en HTML.
- `estado/estado.json` - historias ya reportadas, para no repetirlas.
- `estado/glosario.json` - terminos ya explicados.
- `estado/candidatos.json` - procesos candidatos a automatizar.
- `latido.log` - una linea por ejecucion, siempre, aunque no se publique nada.
